# 本地验收记录与边界

当前交付定位为营销分发的本地验收版本。验收使用本机 PostgreSQL 18；应用使用 `btyx_v2`，测试使用本次创建的独立 `btyx_test_` schema。

## 已验证

- 时间点统一为 Go `time.Time` / PG `timestamptz` / RFC 3339 带时区字符串。单元测试验证 DTO 序列化及前端类型生成；真实 PG 验证旧毫秒数据无损转换、空时间转 NULL、重复迁移及跨时区会话过期边界；后台和小程序 JS 验证带时区上传凭证的过期重试。该时间字段版本曾在本地 `btyx_v2` 备份后迁移并重启，实际接口校验 11 条记录的时间格式，独立无头 Edge 完成 10 个菜单及模拟 TOS 直传回归；未进行真实 TOS/微信或小程序真机联调。
- 请求开始与结束分别记录 `http request started`、`http request completed`，与业务日志共享服务端生成的 `X-Request-ID`；测试验证 handler 执行前已写开始日志、成功/异常/panic/404/405/OPTIONS 各有一对生命周期日志、结束状态与耗时。两端 API 重启后实际验证日志落盘。原有并发隔离、跨域响应头、日志敏感信息排除测试继续通过；真实 PG 验证提现和通知 outbox 保存来源 ID，worker 重试恢复同一 ID。文件日志测试实际触发大小轮换、gzip 压缩及旧备份清理。
- 后端按进程拆分 handler、路由与 worker task；全量路由清单、跨进程鉴权、关闭演示登录、统一 `data,error` 响应及文件/支付回调协议回归测试，使用真实 PG 隔离测试 schema。生产导入检查禁止 `internal` 反向引用 `cmd` 或跨进程引用。
- HTTP 请求和响应使用泛型适配器及具体 DTO；统一 JSON 绑定测试覆盖合法输入、非法 JSON、字段类型、未知字段、强类型枚举和必填校验；绑定失败不调用 handler，空响应及错误响应保持 `data: null`。
- Go 全量单元/PG 集成测试与静态检查，覆盖报名、协议、版本冻结、同日并发领取、同内容多人并发领取、分平台驳回重交、旧修订号审核拒绝、重派新价、失效记录不可恢复、周结算与重复入账、提现冻结及重复终态。
- Ent 枚举、严格 JSON 枚举输入与 PG 枚举 CHECK；包括绕过应用直接写非法状态及非法平台数组的拒绝。
- 数据库不可变触发器；账本修改/删除失败，纠错使用关联调整。
- 支付适配单元测试使用官方 SDK 验签入口；无签名通知拒绝、未知支付状态不当成功、演示身份禁止真实付款。
- worker 的缺配置冻结、配置恢复、超时后查原单、进程中断后原单恢复、回调先到时终态不被覆盖。
- React 金额精度与登录保护测试，TypeScript 检查、生产构建、统一格式检查。
- 独立无头 Edge 使用真实本地接口完成后台登录、10 个菜单读取及退出；截图保存在 `artifacts/screenshots/admin-tasks.png`。
- 文件存储已改为前端直传私有 TOS：官方 SDK 签名策略测试、真实 PG 的待确认/并发/权限/过期测试、React 直传测试和小程序模拟接口测试；凭据缺失明确返回 503。没有连接真实 TOS 桶。
- 应用 schema 已执行 Ent 迁移，添加了标明“本地演示”的协议、内容及任务，没有创建模拟余额或模拟支付成功结果。

测试不等同于真实微信商户或小程序真机验收。按用户要求，未进行小程序开发者工具/真机联调；真实微信配置稍后提供。

4. 权威实名、手机所有权核验方案。当前实现为加密资料收集、格式校验及报名人工审核，不宣称已做实名三要素/微信手机号核验。
5. TOS Bucket、地域、Endpoint、专用 AK/SK、CORS、临时目录生命周期及小程序合法域名；详见 `file-storage.md`。上述小程序模拟接口测试不代表开发者工具/真机验收。

## 扩大使用范围前仍需补齐

- 管理后台目前是单个配置口令对应的管理员身份；多员工账号、细粒度权限和独立操作人归属尚未建立。
- 列表目前使用有限数组与前端分页；服务端分页、筛选、导出及批量查询优化尚未完成。
- 作品链接当前只校验域名/路径及规范化重复，不联网解析短链，不自动抓取播放数据或复核可见性。通过审核由操作人明确确认，异常后重派/照常结算由运营选择。
- 周结算当前由运营预览后手动确认，不自动在每周一批量加钱。每批最多 1000 条，超限拒绝而非漏算。
- 需按正式业务确定提现限额、平台异常时的人工核对、长时间未知单据与历史账单核对流程。
- 当前本机部署监听 loopback、PG 使用本机连接；正式部署的 HTTPS、DB 最小权限、备份恢复、告警、过期会话与孤立上传清理还未实施。

这些是当前实现的实际边界，不会以“按钮禁用”“模拟成功”或放松测试替代后续验收。
